UI Style Gallery

The same components — a nav bar, a hero, buttons, and a card — rendered in fifteen different UI styles. Open them side by side to feel the difference.

Modern

  • Glassmorphism

    Frosted glass panels, backdrop blur, vivid gradients underneath.

  • Neubrutalism

    Thick black borders, hard offset shadows, raw high-contrast colors.

  • Material Design

    Google's language: elevation through shadow, bold accent colors.

  • Minimal / Swiss

    Typography-driven, generous white space, one accent color.

  • Claymorphism

    Puffy plasticine surfaces, pastel colors, dual inner/outer shadows.

  • Bento Grid

    Rounded tiles of mixed sizes and colors — the Apple-keynote look.

  • Kawaii

    Pastel candy colors, chunky rounded shapes, bouncy soft shadows.

Retro & nostalgic

  • Retro Vintage

    Warm paper tones, serif italics, stamp badges — 70s editorial print.

  • Y2K

    Chrome text, icy blues, glossy pills — the turn-of-the-millennium web.

  • Art Deco

    Gilded geometry, sunburst motifs, 1920s machine-age glamour.

  • Synthwave

    Neon sunsets, perspective grids, chrome gradients — the 80s future.

  • Skeuomorphism

    Real-world textures: linen, glossy buttons, stitched leather. The iOS 6 era.

Dark & edgy

  • Dark Neon

    Near-black canvas, cyan/magenta glow, gradient headlines.

  • Cyberpunk

    Glitch typography, HUD brackets, scanlines, terminal aesthetic.

Anti-design

  • Brutalism

    Raw unstyled HTML. Default fonts, blue links, zero CSS. On purpose.
