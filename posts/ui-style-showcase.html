A tour of UI styles — one page, seven looks

October 3, 2026

UI design has dialects. Two sites can contain exactly the same components — a nav bar, a headline, two buttons, a card — and feel like they belong to different planets. To make that visible, I built a small interactive gallery: the same layout rendered in seven different styles.

Open the UI Style Gallery →

Each demo page is a self-contained HTML file with its own inline CSS. Same content, different skin:

  • Glassmorphism — frosted panels floating over gradients; depth created with blur, not shadow.
  • Neubrutalism — thick black borders, hard offset shadows, raw colors; zero subtlety on purpose.
  • Material Design — Google's elevation system; surfaces lift off the page via layered shadows.
  • Minimal / Swiss — typography and white space do all the work; one red accent.
  • Dark Neon — near-black canvas, glowing cyan/magenta accents; glow replaces shadow.
  • Bento Grid — rounded tiles of mixed sizes and colors, the Apple-keynote signature.
  • Claymorphism — puffy, plasticine-like surfaces in pastel colors with dual inner/outer shadows.

Why this is a useful exercise

Styling is surprisingly separable from structure. Every demo shares roughly the same HTML skeleton — the personality comes almost entirely from CSS. That's the whole argument for keeping this blog framework-free: once your markup is clean, reskinning it is a stylesheet away.

The demos live under /ui-styles/ in the repo if you want to study (or steal) the CSS.
