# grsh50.github.io

Personal blog of [trebuh](https://github.com/grsh50), hosted on GitHub Pages.

Plain HTML + CSS, no build step. Pages on the `main` branch are served automatically at <https://grsh50.github.io>.

## Adding a post

1. Create `posts/my-new-post.html` (copy an existing post as a template).
2. Add an entry to the list in `index.html`.
3. Commit and push to `main`. The site updates within a minute.
